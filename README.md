# 📦 UniversalBox 

> **A Time-Aware Personal Digital Life Assistant** > 基于时间感知的个人数字生活助理

UniversalBox 是一款 Android 应用。它致力于解决大学生数字生活碎片化的问题，集成了笔记本，日程表，收藏夹，以及各种实用组件，通过 **Neo-Bento (新·便当盒)** 设计语言，将日程、工具与资源智能连接。

## ✨ 核心亮点 

 采用类 Vision Pro 的空间设计感，3D 图标 + 极光弥散背景。
根据日程（上课/休息）自动推荐 OCR、笔记或娱乐应用。
全局集成 Lottie 动画与 Haptic 触感反馈，提供解压的物理手感。
集成 Google ML Kit (OCR)、ZXing (扫码)、沉浸番茄钟等原生工具。

## 🛠️ 技术栈 

* **Language**: Kotlin (100%)
* **UI Framework**: Jetpack Compose (Material 3)
* **Architecture**: MVVM + Clean Architecture
* **Async**: Coroutines & Flow
* **Database**: Room Database
* **Libraries**: Lottie, Coil, ML Kit, Navigation Compose
